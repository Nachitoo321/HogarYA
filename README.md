# 🏠 HogarYA

Real estate management system developed as a collaborative university project.

The application provides tools for managing properties, clients and real estate operations through a web interface.

## 🚀 Technologies

- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- Thymeleaf
- MySQL
- Maven
- HTML & CSS

## ✨ Features

- Property management
- Client management
- Real estate operation management
- Data persistence with MySQL
- Server-side web interface with Thymeleaf
- Layered application architecture

## 🏗️ Architecture

The project follows a layered architecture to separate responsibilities between the different components of the application.

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
Database
```
